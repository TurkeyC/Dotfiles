# Academic Skill

用于把“选题 -> 查找 -> 综述 -> 写作 -> 文本优化”串成一个可执行的学术工作流，并输出可直接使用的提示词、执行清单和结果模板。

## 何时使用

在以下任一场景优先使用本技能：

- 用户要快速生成并筛选论文选题
- 用户要找到某一方向的高质量论文清单
- 用户要搭建文献综述框架并整理文献
- 用户要写顶刊风格论文的某一章节
- 用户要润色文本、降低AI痕迹、统一文风
- 用户不确定当前处于研究流程哪一步

## 核心原则

1. 先定阶段，再给方案
- 先判断用户处于哪个阶段：选题、查找、综述、写作、优化。
- 阶段不清楚时，先用2-4个问题快速定位，不直接给冗长内容。

2. 先给可执行版本，再给扩展选项
- 每次先给“最小可执行方案”，避免一次输出过载。
- 再提供“进阶可选步骤”，方便用户按时间预算升级。

3. 保持学术严谨与可验证
- 涉及论文推荐时，明确要求用户在 Google Scholar / Web of Science / Scopus 复核。
- 对不确定的信息，用“待验证”标记，避免幻觉式断言。

4. 输出结构固定，便于复用
- 所有输出按统一模板组织，减少用户二次整理成本。

## 工作流

### 阶段A：选题
目标：把模糊兴趣转为可论证的研究题目。

执行步骤：
1. 收集约束：专业、导师方向、资源、时间、禁区。
2. 生成候选题：先广覆盖，再按创新性与可行性收敛。
3. 打分排序：按创新性、可行性、数据可得性、理论价值、实践价值五维评估。
4. 产出 Top 3 论证摘要：研究问题、创新点、方法、风险、备选。

优先参考：
- 论文选题系列/论文选题AI提示词库.md
- 论文选题系列/论文选题论证方案模板.md

### 阶段B：论文查找
目标：在短时间内形成高相关论文池。

执行步骤：
1. 生成关键词与搜索式（核心词、同义词、排除词）。
2. 明确渠道（Scholar、WoS、Scopus、学科数据库）。
3. 产出分层论文清单（必读、应读、扩展）。
4. 给出验证动作：核对题名、作者、年份、期刊/会议、引用数。

优先参考：
- 论文查找系列/论文查找和文献综述AI提示词库.md
- 论文查找系列/AI直接找论文的Prompt.md

### 阶段C：文献综述
目标：构建清晰综述框架并形成可写稿件骨架。

执行步骤：
1. 分类文献：理论、方法、应用、争议、空白。
2. 建立脉络：时间演进 + 分支比较。
3. 输出大纲：章节、字数、关键文献映射。
4. 提炼研究空白：指出你可进入的具体切口。

优先参考：
- 文献综述系列/文献综述AI提示词库.md

### 阶段D：论文写作
目标：完成高质量初稿并支持投稿导向表达。

执行步骤：
1. 先确定叙事主线（核心问题 -> 方法 -> 发现 -> 贡献）。
2. 分段写作（标题摘要、绪论、方法、结果、讨论、结论）。
3. 图表与论据对齐，避免“结论先行但证据不足”。
4. 按目标期刊风格调整语言与结构。

优先参考：
- 论文撰写系列/顶刊论文写作AI提示词库-2.md

### 阶段E：文本优化
目标：让文本更学术、更自然、更一致。

执行步骤：
1. 明确优化目标：润色、扩写、缩写、降AI痕迹、统一术语。
2. 逐段处理并保留术语一致性。
3. 检查逻辑链与证据指向，避免只改表面措辞。
4. 输出“修改说明表”，便于追踪改动原因。

## 输出模板

每次默认输出以下结构：

1. 阶段判断
- 当前阶段：
- 目标结果：

2. 立即可执行步骤
- 步骤1：
- 步骤2：
- 步骤3：

3. 可直接复制的 Prompt
- Prompt A（主方案）
- Prompt B（备选方案）

4. 交付物模板
- 表格字段或章节大纲
- 每项填写说明

5. 质量与风险检查
- 必做核验项
- 常见误区

6. 下一步建议
- 完成当前步骤后，推荐进入的下一阶段

## 交互规则

- 用户信息不足时，先提最多4个关键问题再继续。
- 用户赶时间时，优先给“30分钟版本”方案。
- 用户需要深度内容时，再切换“完整版”。
- 不要求用户一次性完成全部流程，始终支持分阶段推进。

## 质量门槛

- 方案必须可执行，不只给概念描述。
- 论文信息建议必须附验证提醒。
- 输出必须包含阶段、动作、模板三要素。
- 任何结论都要能回溯到用户输入或明确假设。

## 快速示例

示例1：用户说“我想做推荐系统方向硕士论文，不知道选题。”
- 先进入阶段A，生成候选题并给五维评分表。

示例2：用户说“我选题定了，帮我找30篇近5年高质量论文。”
- 进入阶段B，给检索式、论文分层清单和验证步骤。

示例3：用户说“我已经有50篇文献，帮我搭综述框架。”
- 进入阶段C，给结构化大纲和分支比较框架。
